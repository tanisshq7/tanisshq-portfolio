## 🚀 Featured Enterprise Projects

### 1. 🇮🇳 [FinAudit-AI](https://github.com/tanisshq7/FinAudit-AI)
**Autonomous Financial Audit, 4-Way Reconciliation & Risk Intelligence Engine**
- **Architecture**: Autonomous agentic state machine designed for Indian corporate finance and statutory controllers.
- **4-Way Deterministic Reconciliation**: Cross-reconciles GST Invoices (B2B/B2C), Bank Account Statements (HDFC/SBI/ICICI), Payment Gateway settlements (UPI/NEFT/RTGS), and General Ledger vouchers (₹ INR).
- **ML Anomaly Engine**: Unsupervised **Isolation Forest** machine learning algorithms + statistical Z-Score outlier detection.
- **Evidence-Bound Gemini Reasoning**: LLM auditor producing zero-hallucination GAAP/IFRS Adjusting Journal Entries (AJE) and SOX 404 compliance reports.
- **Tech Stack**: `Python`, `LangGraph`, `Google Gemini`, `FastAPI`, `scikit-learn`, `Docker`.

### 2. 🤖 [Enterprise AI Copilot](https://github.com/tanisshq7/Enterprise-AI-Copilot)
**Autonomous Assistant for Corporate Knowledge Bases & Workflow Automation**
- **Architecture**: Production full-stack AI platform enabling corporate teams to query complex unstructured PDF manuals and documents with semantic citations.
- **Agentic Multi-Step RAG**: Multi-step query decomposition powered by LangGraph, ChromaDB vector retrieval, and Google Gemini.
- **Security & APIs**: FastAPI backend secured with JWT bearer token authentication, rate limiting, and Model Context Protocol (MCP) integrations.
- **Tech Stack**: `Python`, `LangGraph`, `Gemini API`, `FastAPI`, `React + Vite`, `ChromaDB`.

### 3. ⚡ [AI-Powered SQL Query Generator](https://github.com/tanisshq7/Ai-sql-query-generator)
**Natural Language to Dialect-Correct SQL & Visual Analytics Platform**
- **Architecture**: Converts plain English business queries into optimized, execution-safe SQL queries.
- **AST Security Sandbox**: Parses SQL Abstract Syntax Trees to strictly prohibit destructive operations (`DROP`, `DELETE`, `UPDATE`, `ALTER`) in production.
- **Performance Optimizer**: Analyzes execution plans, detects anti-patterns, and recommends database indexing strategies.
- **Visual Dashboards**: Automated charting with Recharts and multi-format exports (CSV, JSON, PDF).
- **Tech Stack**: `Python`, `FastAPI`, `React`, `Google Gemini`, `SQLAlchemy`, `Recharts`.

### 4. 🕷️ [WebHarvest-X](https://github.com/tanisshq7/CodeAlpha_WebScraping)
**Enterprise-Grade Config-Driven Scraping Pipeline & Data Quality Engine**
- **Architecture**: Resilient web data extraction pipeline with dynamic YAML config targets, User-Agent header rotation, and schema drift monitoring.
- **Data Quality Scoring (0–100)**: Evaluates dataset completeness, consistency, and field validity using Pydantic models.
- **Executive Dashboard**: Interactive Streamlit management console for pipeline triggering, inspection, and Parquet/CSV downloads.
- **Tech Stack**: `Python`, `BeautifulSoup4`, `Pydantic`, `Streamlit`, `SQLite`, `Parquet`.
